Your code is the body of function(vacuum) { ... }
API (what your code can call):
vacuum.forward() — move 1 square forward (stops with an error if a wall/obstacle is ahead)
vacuum.turnLeft() — rotate 90° left (no movement)
vacuum.turnRight() — rotate 90° right (no movement)
vacuum.isBarrierAhead() — true if the square in front is blocked (wall or obstacle)
vacuum.isInDocking() — true if the vacuum is on the docking station (⚓)
Extra helpers (Map 2: cleaning):
vacuum.cleanedCount() — how many reachable squares you have visited so far
vacuum.totalReachable() — how many squares can be reached in this level (not counting obstacles)
vacuum.coveragePercent() — visited percent (0–100)
vacuum.isAllCleaned() — true when all reachable squares have been visited
Extra sensors (Map 3: line following):
vacuum.isLineAhead() — true if the square in front has the line (or is the dock)
vacuum.isOnLine() — true if you are currently on the line (or on the dock)
